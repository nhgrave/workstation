# Eslint

Configure Eslint to prevent problems and format your code.

## Install

Install eslint and other libs or run eslint setup as `npm init @eslint/config@latest`

```bash
npm install -D eslint globals @eslint/js @stylistic/eslint-plugin
```

Create `eslint.config.mjs` file, if you already have a `.eslintrc.json` you can run `npx @eslint/migrate-config .eslintrc.json` to migrate the file to the new version as `eslint.config.mjs`.
