# Ruby on Rails

## To install ruby

```bash
sudo apt update && sudo apt upgrade

sudo apt install build-essential automake autoconf libreadline-dev libncurses-dev libssl-dev libyaml-dev libxslt-dev libffi-dev libtool unixodbc-dev unzip curl zlib1g-dev sqlite3 libsqlite3-dev

install rbenv
```

### Check ruby version

```bash
ruby -v
bundler -v
gem -v
```

## To install rails

```bash
gem isntall rails
```
